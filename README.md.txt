# IoT Weather Monitoring System

Real-time temperature and humidity monitoring using ESP32 and DHT22 sensor, with data uploaded to ThingSpeak cloud. Developed in Embedded C for accurate sensor readings and IoT integration.

## Features
- Measures temperature and humidity using DHT22 sensor
- Sends data to ThingSpeak cloud
- Displays readings in Serial Monitor
- Enables IoT-based remote monitoring

## Hardware
- ESP32 Development Board
- DHT22 Sensor
- USB Cable & Breadboard

## Software
- Arduino IDE
- ThingSpeak Cloud
